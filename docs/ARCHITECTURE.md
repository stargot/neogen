# Архитектура Neogen

> Заготовка. Уточняется по мере прохождения фаз `backlog.md` (фазы 1–6).
> Гейты из шапки backlog пересмотру без гейта пользователя не подлежат.

## Обзор

Neogen — programming/automation-игра: игрок пишет Lua-скрипты для роверов
и запускает их в детерминированной симуляции. Отображение — Godot 4.x,
ядро симуляции — Rust-крейт без зависимостей от Godot, скрипты игрока —
Lua 5.4 в песочнице.

## Крейты и каталоги

| Путь | Роль |
|---|---|
| `crates/neogen-core` | Детерминированная симуляция: мир, fixed-timestep тик, seed-RNG, роверы, снапшоты. **Не зависит от Godot.** |
| `crates/neogen-script` *(появится в фазе 2)* | Lua-рантайм: mlua (Lua 5.4), песочница без `os`/`io`, instruction budget, планировщик скриптов. |
| `crates/neogen-gdext` | GDExtension-мост (godot-rust/gdext): владеет симуляцией из Godot-ноды, зеркалирует состояние в ноды, дренажирует логи в сигналы. |
| `godot/` | Игровая оболочка: сцены, камера, HUD, IDE (редактор Lua + консоль); здесь же собранный бинарник расширения. |
| `scripts/` | Lua-скрипты игрока — обычные `.lua` файлы в наблюдаемой папке. |

## Поток данных Godot ⇄ Rust

```
 scripts/*.lua ──▶ neogen-script (coroutine + budget)
                        │  команды как данные (MoveTo/Scan/Act)
                        ▼
                  neogen-core (fixed-timestep step)
                        │  состояние мира, LogBuffer, буфер scan
                        ▼
                  neogen-gdext (GDExtension)
                        │  ноды-зеркала, сигнал log_line(tick, rover, text)
                        ▼
                  Godot (рендер, HUD, IDE)
```

- Симуляцию ведёт Godot-нода: в `_physics_process` аккумулятор времени
  даёт ровно один `step()` ядра на фиксированный интервал — независимо от FPS.
- Вызовы Lua-API (`move`/`scan`/`act`/`print`) не исполняются мгновенно:
  они кладут команды в очередь ровера и применяются в тике — это часть
  детерминизма.
- Направление «игрок → ядро» только через файлы `.lua` и UI-команды
  (Run/Stop); рендер — только чтение состояния ядра (с интерполяцией между тиками).
