# MVP-приёмка — Neogen v0.1.0-mvp

Критерий среза MVP (из backlog): **с чистого клона игрок открывает в игре
редактор, пишет Lua-скрипт, запускает его на ровере, видит вывод в
консоли и движение ровера в мире.** Всё.

Галочки ставит приёмщик руками. Любой провал — фиксы до приёмки.

## A. Автоматизированная часть (с чистого клона)

- [ ] **A1. Rust-ядро зелёное**: `cargo test --workspace` — все тесты
      проходят (включая golden-детерминизм и snapshot roundtrip).
- [ ] **A2. Гейты качества**: `cargo fmt --all --check` и
      `cargo clippy --workspace --all-targets -- -D warnings` — без замечаний.
- [ ] **A3. Расширение собирается**: `cargo build -p neogen-gdext --release`
      и артефакт скопирован в `godot/bin/` (см. README «Версии»).
- [ ] **A4. Регистрация расширения**: из `godot/` —
      `godot --headless --import`, затем `godot --headless --quit` —
      в логе «Neogen GDExtension loaded», error-строк нет.
- [ ] **A5. Полный smoke-набор**: из `godot/` —
      `godot --headless --script res://tests/smoke.gd` — `SMOKE OK`
      (мост, редактор, консоль, HUD, зеркало, run/stop).
- [ ] **A6. MVP-сценарий headless**: из `godot/` —
      `godot --headless --script res://tests/mvp_smoke.gd` —
      `MVP SMOKE OK` (сквозной цикл «как игрок»: patrol → Run →
      движение → доклады → Stop → повторный Run).

## B. Сквозной цикл как игрок (окно 1920×1080)

- [ ] **B1. Запуск**: `cd godot && godot` — сцена мира видна: пад,
      грид, ровер-корпус, тёплый свет.
- [ ] **B2. Редактор**: F12 — панель редактора; в списке выбирается
      `scripts/patrol.lua`, код с подсветкой и автодополнением
      (`m` → `move`).
- [ ] **B3. Run**: кнопка Run — ровер едет по квадрату, консоль (`)
      показывает «патруль: вершина …», HUD тикает tick, статус скрипта
      running.
- [ ] **B4. Правка**: в редакторе `SIDE = 8` → `3`, Save — маршрут
      сжимается сам (hot-reload; при синтакс-ошибке — строка
      «hot-reload failed», старый скрипт продолжает работать).
- [ ] **B5. Stop**: кнопка Stop — ровер замирает, HUD статус stopped.
- [ ] **B6. Своё**: создаётся новый файл (New), пишется простой скрипт
      (`move(5,5) print("привет")`), Run — ровер едет и здоровается.

## C. Ручные проверки фаз

- [ ] **C1 (4.1)**: камера — СКМ/пробел+ЛКМ панорамирует, колесо зумит
      к курсору в границах; стартовый зум ~16.7 px/юнит (пад ≈300 px);
      FPS ≥ 60 в мониторе.
- [ ] **C2 (4.2)**: ровер читается как машина (янтарный корпус, нос),
      доворот по курсу, лёгкий сквош на ходу, затухающий след.
- [ ] **C3 (4.3)**: HUD — tick растёт, seed 42, статусы скриптов
      (running/finished/error с текстом).
- [ ] **C4 (6.1)**: подсказка «с чего начать» при старте, закрывается
      кнопкой/Esc.

## Что НЕ входит в MVP

(пост-MVP фазы backlog.md; отсутствие — не дефект приёмки)

- Тайловый мир, биомы, среда, индексы (экология/доверие/гармония) — фаза 7.
- Терраформинг-действия `act` (сейчас заглушка Noop) — фаза 8.
- Сейвы/миграции формата — фаза 9.
- Steamworks и Workshop-шеринг скриптов — фаза 10.
- Арт/звук/туториал/баланс (полировка EA) — фаза 11.
