# Neogen — Backlog разработки

**Проект:** programming/automation-игра (Godot 4.x + Rust-ядро + Lua-скрипты игрока). Сеттинг: соларпанк-утопия 2480, инженер-смотритель обслуживает «Ноосферу». Напряжение — энтропия и legacy-код, мир отвечает индексами экологии/доверия/гармонии.

**Цель конвейера (срез MVP):** игрок открывает в игре редактор, пишет Lua-скрипт, запускает его на ровере, видит вывод в консоли и движение ровера в мире. Всё.

**Зафиксированные гейты (не пересматривать):** Godot 4.x · Rust-крейт симуляции без зависимостей от Godot, детерминированный fixed-timestep, GDExtension-мост · Lua 5.4 через mlua, coroutine + instruction budget · скрипты = обычные `.lua` в наблюдаемой папке · сейвы = снапшот мира + тексты скриптов · Steamworks — поздняя фаза.

**Легенда:** оценка S / M / L (один заход worker'а ≈ S–M; M — плотный заход; L — только для резки на подзадачи) · риск: низкий / средний / высокий ⚠ (⚠ — нужен гейт пользователя) · «Зависит от: N» — порядок обязателен.

**CI (выбор):** GitHub Actions — `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo test` по workspace; позже добавляется headless-прогон Godot-проекта.
